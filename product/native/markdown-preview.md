# 把回复变成好读的页面

这是一段中文正文。**重点文字会加粗**，`行内代码` 有独立底色，[链接文字](https://openai.com) 用蓝色显示。

## 在掌机上继续工作

- **Y 录音**：再按一次停止，识别后先核对文字。
- **A 发送**：确认目标会话后提交；B 可以放弃。
- 长段落按屏幕宽度自然换行。上下滚动，左右整页翻动，不会让文字挤在一起。

> 先确认内容，再发送到电脑上的原会话。

## 操作一览

| 按键 | 功能 | 说明 |
| --- | --- | --- |
| Y | 开始或停止录音 | 识别后确认发送 |
| X | 快捷指令 | 可以切换语句 |
| ← / → | 上一页或下一页 | 适合阅读较长回复 |

## 代码与步骤

```javascript
const message = "你好，掌上助手";
console.log(message);
```

1. 选择已有会话。
2. 查看进度与回复。
3. 核对后发送指令。
