# 产品展示站点验证记录

日期：2026-10-13。验证环境：云端 Linux / Chromium 154；静态 HTML、CSS、JavaScript，无前端构建依赖。

## 本地浏览器验收

以 `/ai-agent-terminal-public/` 项目子路径提供静态页面，分别在桌面 1440 × 1180 和手机 390 × 900 视口验收；另查看初版 1440 × 1060、390 × 844 首屏。已查看两个尺寸的首屏、全页与各章节实际浏览器截图，并修正手机连接图符号换行及正文、触控目标尺寸。

- 默认、EVA / NERV、K-ON!、Pokémon 四皮肤：逐一点击切换，核对选中状态和实际图片加载。
- 阅读进展、核对草稿、查看成果三场景：在四皮肤中逐一验证，共 12 种组合。
- 皮肤方向键操作；场景方向键切换、焦点及 ARIA 状态。
- 首屏与场景原图弹窗：实际图像、关闭按钮、Escape 关闭、焦点返回。
- 手机菜单开关、锚点跳转及自动关闭；桌面导航；所有锚点目标存在。
- 命令复制至浏览器剪贴板成功。
- 每个章节均无页面横向溢出，文档宽度分别为 1440 / 390。
- 两尺寸均无 JavaScript 错误、无失败资源请求；本地资源说明返回 200。
- CSS、JavaScript、字体及图片均从项目子路径加载，无外部素材请求、登录或跟踪。
- `prefers-reduced-motion: reduce` 下页面滚动为 `auto`，无强制动态效果。
- 页面所有 9 个不同的主要 GitHub / 文档链接经当前云端网络代理实际请求，均返回 HTTP 200。
