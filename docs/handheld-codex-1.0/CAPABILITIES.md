## 入口已实现，仍未完成真人端到端验收

| 能力 | 边界 |
| --- | --- |
| 新建会话 | 用户主动选择创建并确认后才调用；沿用当前原会话的已保存本地项目和桌面默认模型。项目匹配、确认及幂等已自动测试，没有为验收额外创建真实任务 |
| 问题/审批状态 | 只展示源端可读取的状态；当前接口没有提供完整原请求对象和决定通道 |
| 动态提示 | 已持久化去重，可静音；完整真实等待、失败、结束事件覆盖和跨会话未读标记仍不足 |
| 语音速度 | 实际麦克风按键路径及 30 秒上限已测；30 次合成音频指标不能代替 30 条真人松手到草稿性能及准确率 |
| 重启 | 掌机应用与伴随服务恢复已测；没有重启正在承载本次及其他工作的整个电脑或 Codex Desktop |

## 当前不能在掌机完成

| 操作 | 原因 | 当前结果 |
| --- | --- | --- |
| 原结构化问题答复 | 当前安装的 app-tools 0.1.5 未提供本适配器可调用的原请求答复接口 | 不以普通会话消息冒充 |
| 真实允许/拒绝审批 | 未提供原审批对象、授权范围及提交决定接口 | 相关服务动作返回不可用 |
| 停止原回合 | 未提供对应原 turn 的中断接口及确认闭环 | 不发送“停止”文字充当停止 |
| 首次配对向导 | 尚未实现掌机内的短时配对流程；目前沿用 USB 配置 | 电脑侧配置和撤销/修复 |
| 外网使用 | 没有配置并实测可信远程通道 | 设置页明确显示未配置 |

现有原实例接口已实测：list_threads、read_thread、send_message_to_thread。create_thread、list_projects 入口存在，但创建只做了隔离自动测试。另开 CLI 或 app-server 不算接管这个已打开的桌面实例。

## 自身产品代码还需补齐

这些缺口独立于桌面接口限制：

- 掌机首次配对及录音空间、保留和删除管理。
- 选择项目、固定项目和隐藏会话的完整交互。
- 上一份草稿的恢复、按词编辑和选中语音片段替换；当前提供按字编辑及光标插入。
- 跨会话未读标记、全部等待状态和竞态的真实覆盖。
- 任意宽内容及高分辨率长图的完整阅读。当前宽屏内容区 1760 像素，图片会先缩至不超过 1120×1400；文本成果超过 128 KB 暂不预览，WSL 路径未映射。
- 完整电脑/Codex 重启、真实 IP 改变、外网、真人语音及 30 次源状态变化性能验收。
