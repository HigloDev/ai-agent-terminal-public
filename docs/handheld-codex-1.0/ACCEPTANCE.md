# 掌上助手 1.0 验收清单

日期：2026-10-04。状态：以下均为待验收要求，不是通过记录。0.4 的既有证据仅用于基线，不能直接覆盖 1.0。

每项记录版本、设备、网络条件、操作步骤、源端与掌机结果、时间戳和证据路径。模拟数据用于开发，最终通过必须对应真机和原桌面实例。

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| G01 | 菜单启动与退出 | 中文名和图标正确，独立打开应用，退出回原系统，不影响原任务 |
| G02 | 首次配对 | 掌机完成配对流程；错误/过期凭据拒绝；设备可撤销 |
| G03 | 已有工作 | 与桌面原 ID、标题、项目对应；打开列表不新建或恢复任务 |
| G04 | 焦点和排序 | 后台更新不将当前操作转到另一条任务；所有焦点可见 |
| G05 | 连续对话 | 用户/助手/活动区分清楚；历史分页无重复遗漏；新消息不打断历史阅读 |
| G06 | 按住 Y | 按下录音、松手识别；短按不误发；30 秒上限；设备断开能停止录音 |
| G07 | 草稿编辑 | 修改、重录、放弃、切任务返回均按规范保存；发送目标清楚 |
| G08 | 原会话发送 | 原桌面收到一次且仅一次；掌机显示准确受理状态 |
| G09 | 结构化答复 | 对应原请求的选项/自由文本有效，源端继续执行 |
| G10 | 审批和拒绝 | 真实原审批闭环；范围与源端一致；返回不拒绝 |
| G11 | 请求竞态 | 电脑先处理、请求过期、连续按键、重试均不造成重复执行 |
| G12 | 停止回合 | 停止正确的原回合并确认最终状态，不以普通文本代替 |
| G13 | 可信状态 | 执行、等待、本轮结束、失败、停止和未知与原端一致；连接状态独立 |
| G14 | 通知 | 待处理/失败/本轮结束各提示一次；跨会话可见、可静音、不重复骚扰 |
| G15 | 图片和公式 | 真内容可读，支持放大/平移；超长内容不截断；加载失败可恢复 |
| G16 | 成果和变更 | 文件真实存在且关联原回合；预览/差异与源文件一致 |
| G17 | 断网恢复 | 缓存标记过期；草稿保留；网络恢复不误发或重复提交 |
| G18 | 独立启动与重启 | 电脑服务、Codex、掌机分别重启可恢复；不依赖当前对话重新执行命令 |
| G19 | 地址变化与外网 | IP 改变可恢复；不同外网完成一次真实任务流程；结果单独记录 |
| G20 | 字号与阅读 | 实际屏幕下中文、代码、表格可读；大字模式不遮挡主要动作 |
| G21 | 性能 | 按 PRD 样本量测量按键、状态、语音 P95；分别报告冷启动和热态 |
| G22 | 连续使用 | 2 小时及规定操作次数通过；内存/缓存不无限增长，无草稿丢失 |
| G23 | 更新与回滚 | 可回退到前版；配对、录音、草稿和用户任务不被覆盖 |
| G24 | 完整真实工作 | 离开电脑，仅用掌机了解任务、安排工作、处理问题、查看成果，全流程成功 |

所有必需项通过才可以称完整 1.0。接口限制、外部设备/网络阻塞、产品代码缺口分别记录，不合并成“基本完成”。

## 发布检查

- 可执行文件、源代码、锁定依赖、构建步骤、许可证、安装和回滚说明齐全。
- 能力矩阵与安装版本一致；没有画出来却不可执行的核心操作。
- PRD 目标、模拟样稿、真机运行、用户确认和自动测试分别保存，不相互替代。
- 用户打开应用就能判断如何开始、当前发生什么、下一步该做什么。
