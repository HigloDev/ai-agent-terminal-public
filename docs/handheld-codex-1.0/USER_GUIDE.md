# 掌上助手使用说明

版本：原生客户端与电脑服务 0.6.1，已安装到本机 TRIMUI Smart Pro，2026-10-04。以下旧版“待部署”说明保留为历史记录，以本节最新验收状态为准。

## 开始使用

1. 电脑保持开启，登录 Windows，并打开 Codex Desktop。伴随服务会在登录后自动启动。
2. 掌机与电脑连接同一家庭局域网，从应用菜单打开“掌上助手”。
3. 工作台先显示需要关注和正在执行的会话。看右上角连接状态、每条会话状态、底部的本轮时长与同步时间。
4. 方向键选择，A 打开。X 打开会话操作菜单；L/R 切换工作台、会话、待处理、成果、设置。

## 按键

| 按键 | 当前作用 |
| --- | --- |
| ↑↓ | 选择、滚动；确认页阅读长草稿 |
| ←→ | 对话翻页；宽屏阅读和图片平移；编辑时移动光标 |
| A | 打开、确认菜单项、确认发送；图片放大；键盘输入 |
| B | 返回。草稿保留，不自动发送 |
| X | 会话操作；确认页进入编辑；编辑时删除前一字 |
| 按住 Y | 录音，松开转文字。编辑中可在光标处插入识别文字 |
| L/R | 切换模块；图片浏览中切换图片 |
| START | 连接设置 |
| SELECT | 退出回掌机系统 |

录音最长 30 秒，短于约 0.25 秒的误触不会上传。转写后先核对标题和文字，再按 A 发送。电脑本地 GPU 完成识别，录音保存在掌机和电脑，没有上传到云端语音服务。

## 左右摇杆与连续翻阅

- 左摇杆：列表和菜单中移动选择；会话、文件中上下慢速连续滚动；普通阅读左右翻页，宽屏阅读左右平移。
- 右摇杆：会话、文件中上下快速连续滚动；列表上下每次跨三个条目；普通阅读左右翻页，宽屏阅读左右平移。
- 图片模式：两个摇杆均可四向平移，右摇杆更快，到图片边缘停止。
- 草稿和键盘：摇杆沿用方向键的移动规则，不确认、删除或发送内容。
- 方向键：轻按一步；按住约 0.35 秒后持续上翻、下翻或移动选择；松开停止。
- 摇杆推得越远，阅读滚动越快；回到中心立即停止。中心小幅晃动不会触发，扳机不参与滚动。
- 打开菜单、返回或切换页面后，如果摇杆仍被推着，需要先回到中心再推动，避免误选。录音期间不滚动。
- 连续滚动针对已经加载的内容；到当前内容边界停止。更早历史仍通过 X 菜单“查看更早 / 后续内容”加载。
- 按住 Y 录音、松手识别、A 核对后发送保持原操作。

## 草稿与编辑

X 菜单中的“恢复当前草稿”打开该会话自己的草稿。X 进入编辑，左右移动光标，X 删除；A 打开小键盘，方向键选择、A 输入、B 收起。键盘提供英文字母、数字、标点和常用中文词。任意中文仍以语音插入为主要输入方式。

上下可阅读长草稿，编辑时移动到相邻段落。B 保存并返回；切换会话后恢复的是对应会话的草稿。草稿容量约 8 KB。

发送中不要重复操作。出现“结果未知”时，草稿会锁定；A 只查询电脑保存的回执，不会再次发送。如果电脑确认受理，程序清除已发送的草稿；仍未知时保留原内容，应核对原会话。不能用重录绕过这个保护。

“已受理”表示电脑版接收了指令。任务是否完成，请继续看原会话状态与回复。

## 阅读与成果

- X → 回到最新回复：跳到最近内容。
- X → 查看更早 / 后续内容：对话加载更早内容；成果文件加载下一页。
- X → 展开 / 收起活动：查看工具与文件操作的状态。
- X → 查看成果文件：选择真实项目文件。A 预览，X 查看源端提供的变更。
- X → 图片与公式：A 放大，方向键平移，L/R 换图，X 重试。
- X → 宽屏阅读：左右平移长代码、表格。
- START → A：切换标准 / 大字。X 切换动态提示的静音设置。

正在看历史正文时，新回复会提示“有新回复”，保留当前内容。文件分页使用打开时的快照；重新打开才读取后来修改的文件。源端截短的变更会明确标记为部分差异。文件超过 128 KB 或类型暂不支持时会说明限制。

## 创建会话

在已有会话的 X 菜单选择“创建新会话”，输入任务，再按 A 明确创建。使用该原会话对应的已保存本地项目及电脑版默认模型；没有匹配项目时会说明原因。不会因为启动、刷新、按 Y 或浏览列表自动创建。

此入口的确认、项目匹配及重复提交保护经过自动测试；没有为验收额外创建真实任务。

## 连接中断

黄色“连接中断 · 缓存”表示正文和任务状态可能过期，草稿仍保留。网络恢复会自动重新读取。电脑地址失效时，程序尝试局域网广播发现，再校验已配对电脑的公钥指纹。

当前没有配置外网可信通道。离开这一个局域网后，远程使用尚未验收。

## 当前限制

电脑版现有接口支持读原会话、发送和创建，尚未提供本程序可用的原审批、结构化问题答复与停止回合接口。因此待处理页不能完成这些决定，应在电脑版处理。

完整 1.0 验收还包括首次配对界面、外网、电脑与 Codex 重启、真实人声性能和完整任务闭环。当前版本标为受限预览，不能把安装成功或单项测试通过当作完整 1.0。

## 更新、回退与撤销

电脑项目中的 install-device.ps1 会先检查程序已经退出，备份前版，逐文件核对后更新。录音、草稿和阅读记录保留。回退使用 -Rollback；回退后的前版通过兼容协议继续读原会话。

撤销掌机访问：在电脑运行 node revoke-device.mjs --confirm。旧凭据失效，重新接入需 USB 连接后运行 install-device.ps1 -RepairPairing。当前仍是电脑侧配置方式，首次配对和撤销的掌机界面尚未完成。

电脑保持当前项目目录不变，开机启动才能找到服务。不能把含有 .local 或 auth.conf 的文件夹当公开安装包发送给别人。
### 最新消息（0.5.4）

打开会话默认显示最新内容。在底部阅读时自动跟随新回复；上翻阅读时保留当前位置，可通过 X → 回到最新回复返回底部。发送回执按时间放到相关回复之前，旧回执不再占据最新页面末尾。

### 流式语音（0.5.5，待真机部署验收）

按住实体 Y 后，录音卡片显示实时识别文字；松开 Y 后进行整段校正，核对草稿后按 A 发送。录音最长 30 秒。实时文字可能变化，识别失败时仍保留原录音和已有草稿。临时识别文本另外保存在 recordings 中，不自动发送。

电脑复用 WSL 的 $HOME/funasr-gpu 环境；流式 Paraformer 与已有离线 SeACo 模型分别负责实时显示和最后校正。录音通过原有 HTTPS 配对连接传输，在本机 GPU 识别，不调用云端语音 API。

恢复到同一电脑时，流式模型位于 product/native/.local/stream-model；交付压缩包不包含约 0.89 GB 模型。需要重新准备时在 Windows 运行 python product/native/setup-stream-model.py，脚本下载官方模型并核对每个文件的 SHA256，然后重启本项目桥接服务。原有 WSL Python 环境和离线模型仍是前提。

当前 USB 未连接，0.5.5 安装和真人语音体验验收尚未完成。电脑侧固定样本约 1.87 秒首次出字，之后约 0.6 秒更新；这些数据不代表掌机真人录音延迟。

## 桌面看板与提醒（0.6.0，待真机部署）

- 聊天页底部的 Y 提示代替常驻语音栏目。正文阅读区从 370px 扩展到 470px；录音时才展开实时文字卡片。
- 用 L/R 切换到“桌面看板”。显示电脑同步时间、CPU、内存、GPU 负载与温度、开机时长、Codex 连接、语音状态和任务数量。电脑数据每 10 秒刷新，超过 30 秒未同步会标记缓存。
- Codex 用量来自桌面官方 get_usage_limits。显示账户共享窗口的剩余百分比、重置时间、额外额度和可用重置次数；每分钟更新。未知值不会显示为 0，也不会自动使用重置次数。多个窗口用 ↑↓ 翻阅。
- 天气城市尚未设置。可在电脑运行 python product/native/setup-weather.py 城市名；同名城市可通过 --index 选择。使用 Open-Meteo，每 10 分钟刷新；服务失败时保留缓存。只请求用户设置城市的天气，不自动定位。
- 看板 A 循环墨绿、深蓝、暖沙三种背景；上传自定义图后增加第四种。电脑运行 product/native/set-wallpaper.ps1 -Image 图片完整路径，之后重新打开掌上助手并按 A 切换。
- X 切换静音、仅通知、全部提示音；默认仅通知。录音时禁用声音。内置导航、确认、返回、发送、完成、待处理、错误 7 种原创短音。
- START 切换常亮，B 回工作台。常亮只在看板生效；退出看板会恢复 SDL 正常屏保策略。掌机系统级休眠是否被阻止仍需真机验证。
- 本轮回复完成使用蓝色提示条、轻微底色变化和完成音；待处理使用琥珀色，错误使用红色。提示按会话、轮次和状态去重；文字状态不会因为静音消失。“本轮完成”不代表整个项目全部完成。

当前掌机 USB 未连接，0.6.0 的真实扬声器、按键、常亮、壁纸及流式麦克风验收均待设备接回后完成。

## 0.6.1 真机更新（2026-10-04）

已完成 USB 安装、程序哈希核对、看板与用量显示、壁纸切换、提示音播放，以及扬声器固定样本经真实麦克风录入的流式出字和松手校正测试。测试录音不发送，测试前的空草稿已恢复。

实时音频改为只传新增片段，避免弱网中反复上传整段录音；松手后继续用完整录音校正。样本复测在录音约 6 秒时已显示接近完整文字，松手后约 2 秒校正完成。这不是首次出字的精确测量，也不是复杂环境准确率验收。

常亮除了 SDL 设置，还使用只属于本程序的 10 秒限时系统唤醒锁；看板中每 2 秒续期，关闭常亮、离开看板或退出释放。进程异常退出时锁自动到期。该设备已验证开关与系统锁联动；未做整夜续航测试。设备原有 dimtime=-1，未修改全局亮度或休眠配置。

天气城市仍未设置，天气栏保持明确占位。蓝色壁纸、常亮及仅通知声音作为本次收尾状态。

### 0.6.4 独立项目入口
X 操作 → 新建独立项目，按住 Y 描述任务，核对后 A 确认创建。通过 Codex 独立工作目录入口建立文件夹和会话；不会复用当前项目目录。当前接口无法加入桌面项目列表，确认页已显示这一限制。新建目录名称由任务首行及请求标识生成。

### 0.6.5 简化入口
左侧主菜单第二项就是“新建项目”。从工作台按 R 一次进入，直接按住 Y 说任务，核对后按 A 创建。也可按 A 先打开输入页。

### 0.6.6 语音流程
录音、松手校正及按 A 发送共用原处卡片，文字就绪后无需进入第二个确认页。松手后优先只上传音频尾段，仍使用完整录音进行校正；网络或缓存异常时回退整段上传。


## 0.6.8 新会话可见性修复

收到创建成功回执后立即打开新会话，返回时进入“会话”列表并保留选中项。旧列表尚未同步时保留新会话入口，标题和回复随后同步；同时清除上一个会话的历史页状态，避免停在“正在读取”。


## 0.6.9 回答 Codex 问题（2026-10-05 已安装并验证真机链路）

在“待处理”中选会话按 A，或在会话 X 操作菜单选择“回答待处理问题”。方向键上下切换原选项，A 选定；L/R 切换题目，X 填写自定义答案，按住 Y 口述后松开识别，A 保存本题答案。全部填写后按 START 核对，再按 A 提交；B 返回修改或退出答题，不代表拒绝。长题目和答案可用左右方向键滚动阅读。

答案单独保存，不覆盖普通会话草稿。提交绑定原请求；问题已过期时拒绝提交，结果未知时不重复发送。当前接入支持普通用户输入问题及桌面 onboarding 问题，不包括权限审批、密文输入、第三方复杂表单和 option picker。实现使用当前 Desktop 的本地多窗口通信协议，应用更新后需要复验兼容性。已在 TRIMUI 上验证选项切换、多题核对、退出后答案恢复，以及通过掌机按键提交到电脑原问题。语音验收使用扬声器播放测试语音、掌机麦克风实际录制，并通过 Y 按住/松开事件完成识别和填答；未替代真人复杂环境准确率测试。控制器键盘的完整文字输入本轮未做实机复测。

## 0.6.10 断线时如何恢复

从会话或工作台按 START 进入连接设置，按 A 重新连接。程序重新搜索已配对电脑、校验电脑身份并刷新会话。正在录音或编辑草稿时先结束当前操作并返回。Wi-Fi 未就绪时按 SELECT 退出，进入掌机系统设置恢复 Wi-Fi 后重新打开掌上助手。电脑服务不可达时检查电脑唤醒、同一网络和伴随服务；提示 Codex 未连接时在电脑打开 Codex。此版本不能远程唤醒已休眠电脑。字号改为 Y，声音仍为 X。

实机验证：旧地址失效后按 A，在 6 秒观察窗口内找到正确电脑并同步；Wi-Fi 关闭 22 秒显示离线，恢复后在 10 秒观察窗口内恢复同步。测试未发送任务消息。
